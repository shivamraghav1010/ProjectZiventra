# UrbanVista — Luxury Real Estate Landing Page & Platform

A high-performance, modern real estate web application crafted with pixel-perfect precision from the UrbanVista Figma design. Built with React (Vite), Tailwind CSS, Framer Motion, and a Node.js/Express backend with MongoDB authentication.

---

## 🌟 Key Features

- **Hero Showcase:** Frosted glass panel, volumetric mist atmosphere, transparent navigation, and luxury villa architecture.
- **Trusted Solutions & Services:** Responsive 4-card interactive grid for buying, renting, investing, and selling.
- **Featured Properties:** Edge-to-edge luxury property banners with frosted dark details cards and quick explore actions.
- **Why Choose Us:** Split-layout highlight card featuring the Victorian mansion cutout and numbered value propositions (.01 to .04).
- **Interactive Testimonials:** Horizontal client reviews carousel with smooth scroll animation.
- **Interactive FAQ:** Animated accordion addressing common homebuying questions.
- **CTA Banner:** Floating pool villa showcase card with stylized UrbanVista atmospheric footer gradient.
- **Full-Stack Authentication:** Node.js/Express API with JWT token authentication stored in `localStorage`, bcrypt password hashing, and MongoDB models.

---

## 🚀 Quick Start

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18+ recommended)
- [MongoDB](https://www.mongodb.com/) (running locally or MongoDB Atlas connection URI)

### 2. Run Backend
```bash
cd backend
npm install
npm run dev
# Server runs on http://localhost:5000
```

### 3. Run Frontend
```bash
cd frontend
npm install
npm run dev
# Vite dev server runs on http://localhost:5173
```

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite, Tailwind CSS, Framer Motion, Lucide React
- **Backend:** Node.js, Express, MongoDB (Mongoose), JWT, Bcryptjs, CORS, Dotenv
